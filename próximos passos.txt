Passo 1 — preencher o .env
EVOLUTION_API_URL=http://<ip-ou-dominio>:8080
EVOLUTION_API_KEY=<sua-chave>
EVOLUTION_INSTANCE=clinica

Passo 2 — testar só a Evolution API
python scripts/test_evolution.py 5511999999999

Isso verifica se a instância está conectada e envia uma mensagem de teste para o número que você passar.

Passo 3 — testar o fluxo completo sem N8N
# Em um terminal, sobe a API
uvicorn app.main:app --reload

# Em outro, simula o que o N8N faria
curl -X POST http://localhost:8000/webhook/message \
  -H "Content-Type: application/json" \
  -H "x-api-secret: <API_SECRET>" \
  -d '{"phone": "5511999999999", "message": "quais exames vocês fazem?"}'

O retorno JSON confirma que o LangGraph processou, e a mensagem já chega no WhatsApp via send_text. N8N só entra depois como camada de roteamento de webhook.
